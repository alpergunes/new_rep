# LangchainIntro

Bu proje, Langchain ile ilgili temel örnekleri ve kullanım senaryolarını içerir.

## Dosyalar
- `serve.py`: Sunucu başlatma kodları
- `simplemessage.py`: Basit mesaj örneği
- `simplemessagewithparser.py`: Parser ile mesaj örneği
- `simplemessagewithparserandchain.py`: Parser ve zincir ile mesaj örneği
- `simplemessagewithparserchainandtemplates.py`: Parser, zincir ve şablon ile mesaj örneği

## Gereksinimler
Gerekli paketler için `requirements.txt` dosyasını inceleyin.

## Ortam Değişkenleri
`.env` dosyasına aşağıdaki anahtarları ekleyin:

```
OPENAI_API_KEY=
LANGCHAIN_API_KEY=
LANGCHAIN_TRACING_V2=true
LANGCHAIN_PROJECT=SIMPLELLM
```
